# 🎯 The Ultimate Guessing Game

A polished, interactive Command Line Interface (CLI) number-guessing game built with Python. Features custom range configurations, input validation to prevent crashes, and an arcade-style dynamic performance ranking system!

---

## ✨ Features

- ⚙️ **Custom Difficulty Range:** Set your own minimum and maximum numbers.
- 🛡️ **Crash-Proof Input Validation:** Handles accidental character or symbol entries gracefully without killing the game or penalizing your attempts.
- 📊 **Dynamic Performance Ranking:** Get ranked based on your performance:
  - 🌟 **GODLIKE GUESSER!** (1-3 attempts)
  - 👍 **SHARPSHOOTER!** (4-7 attempts)
  - 🐢 **SLOW & STEADY!** (8+ attempts)
- 🎨 **Retro ASCII Aesthetics:** Clean layout with stylized text arts and real-time response counters.

---
